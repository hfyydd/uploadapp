# 大文件上传应用

这是一个使用Python和Gradio构建的大文件上传应用程序，支持上传、查看和管理文件。

## 功能

- 上传大文件，支持进度显示
- 支持多文件同时上传
- 查看已上传文件列表及大小
- 删除单个或所有已上传的文件
- 显示存储空间使用统计
- 自动处理同名文件（添加时间戳）

## 安装依赖

推荐使用uv进行安装：

```bash
uv pip install -r requirements.txt
```

或使用pip：

```bash
pip install -r requirements.txt
```

## 运行应用

### 基础版本

```bash
python app.py
```

### 增强版本

```bash
python app_enhanced.py
```

应用启动后，可以通过浏览器访问提供的URL（通常是 http://127.0.0.1:7860）。

## 使用说明

1. 上传文件：
   - 在"上传文件"标签页选择一个或多个文件
   - 点击"上传文件"按钮开始上传
   - 上传进度和结果会实时显示

2. 管理文件：
   - 在"管理文件"标签页可以查看所有已上传文件的列表
   - 输入文件名并点击"删除文件"按钮可删除指定文件
   - 点击"删除所有文件"可清空上传文件夹
   - 点击"刷新文件列表"可更新文件列表

## 两个版本的区别

- **基础版本 (app.py)**：简单实现，功能完整但界面简单
- **增强版本 (app_enhanced.py)**：
  - 美化的用户界面（图标和布局）
  - 支持多文件同时上传
  - 实时进度显示
  - 文件表格视图
  - 存储空间统计
  - 自动处理文件名冲突

## 目录结构

- `app.py` - 基础版应用程序
- `app_enhanced.py` - 增强版应用程序
- `requirements.txt` - 依赖文件
- `uploads/` - 上传的文件保存在此目录（自动创建）

## 自定义配置

在`app_enhanced.py`中，您可以修改以下配置选项：

```python
UPLOAD_FOLDER = "uploads"  # 上传文件的存储文件夹
MAX_DISPLAY_FILES = 50     # 最多显示的文件数
ALLOWED_EXTENSIONS = None  # 设置为None允许所有文件类型，或指定列表如 ['.pdf', '.txt', '.jpg']
```
